These records preserve architecture decisions, planning handoffs, implementation
handbacks and review evidence accumulated while delivering the REPL and Sidekick.
Each record describes its own revision and date. Historical verdicts and delivery
status are snapshots; consult the current issue, source and latest handoff before
using an older record as an assignment.

This archive includes written Markdown records. Copied source trees, generated
captures, logs, executable probes and binary archives remain local evidence and
are not included. References to those artifacts describe the original review
environment; they are not a claim that the artifacts ship in this repository.
