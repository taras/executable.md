pair is embedded unchanged in one sheet. The full original History-wide,
question-wide and settled-wide reference PNGs were additionally opened to read

The original Time Travel frame independently shows a tall entry boundary,
shorter semantic marks, a gold selected checkpoint and a separate paused head.
Its source uses differently coloured tags, attributes, strings and delimiters,
and an ENTER label beside the executable occurrence. The question reference
separates state, title, a subordinate preview and choices within a clearly
bounded surface. The settled reference gives the README and completed write
statement visual priority.

Assessment verdict: **original parity remains unmet**. The baseline is useful
and the merged layout/focus corrections are retained. The gap assessment's
G1–G6 and proposed matrix define the next review. Historical V1–V6 definitions
are unavailable and are not assigned fabricated verdicts.

Limits: reference renders are inherited derivatives, scene mapping is
provisional, and a screen cannot prove invisible node/input ownership. The
existing regressions cover that ownership separately. Cold hashes demonstrate
the read-only boundary; they do not establish visual resemblance.
